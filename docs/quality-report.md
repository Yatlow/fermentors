# דוחי בקרת איכות — מימוש מיידי ללא OAuth חיצוני

## זרימת דיווח
טופס ציבורי ב־Firebase → Cloud Function (אימות Turnstile, קובצי מדיה, Rate Limit)
→ שמירה זמנית פרטית ב־Firestore + Cloud Storage
→ POST חתום ומוגבל בזמן ל־Apps Script עצמאי של `brewcrew@shapirobeer.co.il`
→ כתיבה מיידית לגיליון, יצירת קישורי Drive ושליחת מייל ליוחאי.

**אין המתנה של 5 דקות.** במקרה תקלה בהעברה, הדיווח נשאר בתור ומקבל אסמכתה זמנית,
וניתן להפעיל את `qualityRecoverQueued` ידנית. אם הסקריפט סיים לכתוב ולשלוח,
הטופס מציג מספר פנייה אמיתי.

## למה בכל זאת Cloud?
הטופס פתוח לכולם; בניגוד לאפליקציית פרמנטורים, אין משתמש מחובר עם Firebase ID Token.
Cloud Function בודק CAPTCHA, ולידציה, הרשאות מקור, גודל וסוג קובץ ומניעת הצפה,
ושומר את החתימה הסודית בצד השרת. הדפדפן **לעולם אינו מחזיק מפתח ל־Apps Script**.

## הפרדה מהמבשלה
אין לשנות את `server/` או את `server/.clasp.json`; עובדים בפרויקט עצמאי:
`quality-appsscript/Code.js`, `quality-appsscript/appsscript.json`.
נדרש פעם אחת אישור של חשבון brewcrew, יצירת secret משותף והפצת Web App
המריץ כבעל החשבון. הקישור עצמו ציבורי, אך שום פעולה לא מורשית ללא חתימת HMAC.
אם מדיניות האבטחה אוסרת גם שירות ציבורי חתום, אין לפרוס ללא אישור — זה אינו
פתרון לעקיפת מדיניות הארגון.
