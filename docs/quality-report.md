# מערכת דיווחי תקלות — מבשלת שפירא

**ההחלטה המעודכנת:** שימוש בפרויקט Apps Script הנוכחי של הפרמנטורים,
ללא חשבון brewcrew וללא פרויקט נפרד. לתיעוד ההקמה:
`docs/quality-current-script.md`.

הטופס הציבורי נשלח ל־Cloud Functions, שמאמת קלט וקבצים ושולח מיד בקשה
חתומה מסוג `QualitySignedDispatch` ל־Apps Script הקיים.
`server/post.js` מטפל בחריג היחיד הזה; כל הפעולות הישנות נשארות עם אימות
Firebase ID Token ו־approvedUsers.

המודול `server/QUALITY_REPORT_SERVICE.js` מטפל מיד בכתיבה ל־Google Sheets,
העלאה ל־Google Drive ושליחת מייל ליוחאי. מייל אחד לכל דיווח. החל משלושה
אירועים נפרדים באותה בירה ואותה אצווה מציינים זאת במייל עצמו.
אין דוח שבועי ואין סריקה מחזורית רגילה.

גיליון קיים: `19urjK3mUk1vO1clZ2IFDq-3ORqLeX5edBLmBeDwIud4`.
תיקיית מדיה: `1FrGg-gBKRyCSsw4EHTq8qb6zJEpWaQSn`.
ה־Webhook שולח רק מזהה דיווח, זמן וחתימה — לא פרטים אישיים.
לפני הפעלה נדרש לאשר את גישת חשבון הפריסה הקיים ואת ההרשאה החדשה
לשליחת מייל, להגדיר סוד חתימה, ולעבור בדיקת קצה מבוקרת.

אין למזג או לפרוס את הקוד החי בטרם הושלמו אישור הגישה ובדיקות התרחישים.
